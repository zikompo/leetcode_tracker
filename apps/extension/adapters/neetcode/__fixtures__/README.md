# NeetCode fixtures

Shapes read from neetcode.io's client bundle on 2026-11-21, not captured from a real
submission (that needs a signed-in account). The field names are NeetCode's; the values,
and the units of `time` (seconds) and `memory` (kilobytes), are assumptions to check.

To capture real payloads, load a development build (`pnpm --filter @leettrack/extension dev`),
turn on NeetCode in Settings, submit on neetcode.io, and copy the `[leettrack:record]` line
from the page's console.
